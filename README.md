# Hey, I’m Nay 👋

I build software for **Minecraft: Bedrock Edition**, from network protocols and server internals to plugins and browser tools. I like tracing how things work under the hood and building the pieces I wish already existed.

## Selected projects

| Project | What it does |
| --- | --- |
| [Falcon](https://github.com/Falcon-MC/Falcon) | A Bedrock server written from scratch in C++, with its own networking, NBT, and world storage libraries. |
| [Amethyst](https://github.com/NaySurGithub/Amethyst) | A prediction-based anti-cheat for PowerNukkitX. It simulates player movement on the server and compares it with what the client reports. |

## Open source

I contribute to [PowerNukkitX](https://github.com/PowerNukkitX/PowerNukkitX). One recent change brought [end crystal and ravager collision sizes](https://github.com/PowerNukkitX/PowerNukkitX/pull/3364) in line with Bedrock.

I work mostly with **C++**, **Java**, and **Go**, and use web tooling when a project belongs in the browser.
